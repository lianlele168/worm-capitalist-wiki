Separate a description from a test

The published feature list mentions workers, but this does not verify every automation feature in every build. Older player suggestions are not proof that a feature has shipped.

Observe before relying on it

Record the exact feature name. Observe whether it buys, collects or only assists another action. Note whether the game remains in the foreground. Do not infer offline earnings or background-tab behavior from a short active session.
