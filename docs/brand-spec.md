# Worm Capitalist Brand Spec

Visual direction: pixel incremental dashboard with a muddy-gold / leaf-green / mauve palette. Use official screenshots and cover art as first-screen proof, then functional panels for calculator, checklist, and route cards.

Avoid:

- Pure text article pages with no tool or screenshot context.
- Pretending unconfirmed automation features already exist.
- Overly cute ghost-town language from the source template.
